# 自定义音效包规范

想用自己的声音替换内置音色？导入一个**文件夹**即可，无需改代码。

## 文件名约定

音频引擎按**文件名前缀**自动匹配声音槽位：

| 文件名前缀 | 匹配场景 | 示例 |
|---|---|---|
| `down` | 普通按键**按下** | `down.mp3` |
| `up` | 普通按键**回弹** | `up.wav` |
| `space` | **空格** | `space.ogg` |
| `enter` | **回车** | `enter.mp3` |
| `backspace` | **退格** | `backspace.m4a` |

- 支持格式：`wav` / `mp3` / `ogg` / `m4a` / `flac`。
- 大小写不敏感（`Down.mp3` 也算）。
- 每个槽位只取识别到的**第一个**文件，其余忽略。
- 编号名也支持：`down_01.mp3`、`down-coffee.wav` 都算。

## 导入步骤

1. 新建一个文件夹，把音频文件按上述命名放进去。
2. 打开应用 → 设置面板 → **自定义音效包** → **📁 导入音效包**。
3. 选中该文件夹。成功后会显示已载入的槽位。

> 「清除音效包」一键恢复合成音色。

## 优先级

- `space` / `enter` / `backspace` 槽位**只作用于对应特殊键**。
- `down` / `up` 槽位作用于所有**普通按键**（特殊键仍优先用自己的槽位）。
- 未提供的槽位继续使用内置合成音色，互不影响。

## 建议

- 取**短促**的打击音（< 200ms），长音会随着快速打字叠花。
- 音量保持在一个水平（不要忽大忽小），播放时应用仍会做随机音量微调与变速。
- 干净利落的瞬态（attack 快、无明显尾音）听感最好。
