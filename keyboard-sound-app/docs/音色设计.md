# 音色设计与合成原理

本应用**不携带任何音频素材**——8 套音色全部由 [Web Audio API](https://developer.mozilla.org/zh-CN/docs/Web/API/Web_Audio_API)
在运行时逐键合成。本文介绍合成体系，以及每个音色「配方」的结构。

代码位置：`renderer/audio.js` → `PROFILES`。

## 抽象：一个音色 = 若干「part」

每个音色是一个对象：

```js
const PROFILES = {
  blue: {
    down: [ /* 按下时播放的 part 列表 */ ],
    up:   [ /* 回弹时播放的 part 列表 */ ],
  },
  // ...
};
```

一个 `part` 是**极短声音**的声明式描述，两种类型：

### osc（振荡器声源）

```js
{ type: 'osc',                 // 标记为振荡器
  wave:  'sine',               // 波形: sine | triangle | square | sawtooth
  f:     261.63,               // 基频 Hz
  slideTo: 520,                // 可选：结束频率（作频率滑落 → 水滴）
  dur:   0.11,                 // 起音后到衰减完的时长（秒）
  amp:   0.32,                 // 峰值振幅（相对）
  atk:   0.001,                // 起音时间（秒）
  detune: 5,                   // 可选：失谐 cents（模拟真实乐器）
}
```

渲染流程：`start` → 线性起音到 `amp` → **指数衰减**到 0。指数衰减最贴近乐器的自然衰变。

### noise（滤波噪声）

```js
{ type: 'osc' → 'noise',
  filterType: 'highpass',        // 滤波器类型
  filterFreq: 3200,              // 截止/中心频率
  filterQ:    0.7,               // 可选：品质因数（bandpass 用）
  dur, amp, atk,                 // 同上
}
```

噪声用**共享 2 秒白噪声缓冲** + 全局偏移取样，各类 click / snap / 金属声都靠它。

### 延迟 part

part 带 `_delayed: true` 会被延后 ~40ms 播放，用于模拟「二次回响」（麻将桌面反弹、
打字机敲击尾音、木鱼回弹）。

## 合成手法与听感来源

| 音色 | 关键手法 | 听感目标 |
|---|---|---|
| **青轴** | 底部 200Hz 塑料 + 540Hz 段落感 + 3.2kHz 高通 click；回弹 4.2kHz 咔哒 | 清脆段落 click，最「机械」 |
| **红轴** | 135Hz 闷响 + 柔和 mid 噪声，回弹极轻 | 线性、安静、无段落 |
| **打字机** | 120Hz 机身筒 + 300Hz 方波金属 + bandpass 金属噪声 + 延迟尾音 | 老式打字机的撞击 |
| **木鱼** | 640/950/1330Hz 多模衰减 + 高频 sharp + 延迟回弹 | 空心木质「叩叩」 |
| **水滴** | 900→520Hz `slideTo` 快速指数衰减 | 下行的「滴」 |
| **钢琴** | 131Hz 低音 + 三角波基音 + 1 / 2.02 / 3.1 / 4.15… 非谐泛音 + 随机 detune；回弹制音器低通噪声 | 木质低音 + 泛音的琴味 |
| **八音盒** | 1046Hz 基频 + 2.0/3.0/4.2 倍频泛音，长衰减 + 轻微 detune | 明亮、延音的音梳 |
| **麻将** | 3.8kHz click + 1180/1650Hz 瓷片耳鸣 + 低通桌面反弹 + 延迟二次回响 | 干脆的「喀」 |

### 钢琴 / 八音盒的泛音

乐器感主要靠**非谐泛音**与**轻微失谐**：

```
钢琴:  base * [1, 2.02, 3.10, 4.15, 5.20, 6.36]  每个 detune = ±5 cents
八音盒: base * [1, 2.0, 3.0, 4.2]                 每个 detune = ±4 cents
```

纯正弦音色（基音整数倍）听感空洞；加入略微**偏离整数倍**的泛音 + 随机失谐，
才能模拟真实琴弦/音梳的「肉感」。

## 场景与手感如何叠加

- **场景**：`sceneMultiplier()` 返回整体增益（专注 0.55 / 游戏 1.38 / 深夜 0.38；
  深夜自动降音再 ×0.5）。专注模式还叠加**雨声**（循环白噪声 + 高通 + 带通 + 低频 LFO）。
- **手感增强**：
  - `按输入的快慢`：主进程算 `pitchFactor`（约 `0.72 + 击键/秒 × 灵敏度`，钳到 `[0.72,1.9]`），
    通过 `playbackRate` 变速并把振荡器频率整体上移 → 越快越高。
  - `音量随机微调`：每次命中乘以 `1 ± jitter×0.14` 的随机值。
- **特殊键**：优先用自带的 `space/enter/backspace` 配方或回复音色，并乘以单独的音量。
- **回弹**：只有开了「双音效」才播放 `up` part。

## 想新增一套音色

1. 在 `audio.js` 的 `PROFILES` 增加 `down` / `up` 配方（复制最接近的改参数）。
2. 在 `audio.js` 的 `PROFILE_LABELS` 登记中文名。
3. 在设置面板 `renderer.js` 的 `PROFILES` 数组登记卡片（emoji / 简介）。
4.（可选）在 `README.md` 与 `docs/使用指南.md` 的音色表补充一行。
