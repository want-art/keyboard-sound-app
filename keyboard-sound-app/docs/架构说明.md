# 架构说明

面向想读代码 / 二次开发的开发者。先看根目录的 [README](../README.md) 了解功能。

## 总览

```
┌─────────────────────────────────────────────────────────────┐
│                        主进程 main.js                        │
│  · 全局键盘钩子 (uiohook-napi)   · 打字速度计算               │
│  · 配置持久化 (config.json)      · 每日统计 (stats-*.json)   │
│  · 系统托盘 + 全局热键           · 单实例锁                   │
│  └─────── 通过 IPC(webContents.send) 广播给各窗口 ──────────  │
└──────┬──────────────────┬──────────────────┬─────────────────┘
       │ config/统计       │ key 事件         │ key + overlay 配置
       ▼                  ▼                  ▼
  ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
  │  设置面板    │   │ 隐藏音频引擎 │   │ 透明悬浮键盘  │
  │ index.html  │   │ audio.js    │   │ overlay.html │
  │ renderer.js │   │ (Web Audio) │   │ overlay.js   │
  └─────────────┘   └─────────────┘   │ (Canvas 波纹) │
                                      └─────────────┘
```

三个渲染窗口各司其职：

| 窗口 | 可见性 | 职责 |
|---|---|---|
| 设置面板 | 可见，可关 | 配置 UI、实时统计展示 |
| 音频引擎 | 隐藏、常驻 | 接收按键，用 Web Audio 合成声音 / 场景雨声 |
| 悬浮键盘 | 透明无边框、置顶 | 点亮按键、Canvas 波纹，点击穿透 |

## 数据流：一次按键

1. 用户按下任意键 → uiohook 触发 `keydown` 事件到 **主进程**。
2. 主进程 `handleKey()`：
   - 更新 `dayStats`（按键数 / 字符数 / 活跃时长），并写入磁盘；
   - 按滚动窗口算出当前打字速度 → `pitchFactor()`（越快音调越高）；
   - 解析当前键使用的音色（`resolveProfile()`：优先特殊键设置，否则主音色）；
   - **非静音时** 把 `{ type, key, profile, isSpecial, pitch }` 发给音频引擎窗口，
     同时把可打印字符计入速度统计。
3. 音频引擎 `playKey()`：
   - 建一个「本次命中」的瞬态增益节点 = `场景系数 × 随机抖动 × 特殊键音量`；
   - 若有自定义音效包 → 播放对应采样（可变速）；否则按 8 套配方合成；
   - 支持「按压+回弹」双音效，及延迟 part（如麻将的二次回响）。
4. 主进程把 `key` 事件发给悬浮键盘窗口 → 点亮按键 + 波纹，并从 idle 态唤醒。

## 关键模块

### 主进程 `main.js`

- **钩子**：`uIOhook.on('keydown'/'keyup')`，`event.code` 优先，缺失时回退到
  `UiohookKey` 反查的键名。
- **统计**：`dayStats` 按天结算，文件 `stats-YYYY-MM-DD.json`；活跃时长用每秒
  定时器累加「上一秒有击键」的秒数。
- **打字速度**：滚动窗口最近 60 秒的可打印按键，`WPM = 字符数/5 / 分钟`；
  `pitchFactor` 由每秒击键数线性映射到 `[0.72, 1.9]`。
- **配置**：`config.json`，深合并更新；每次变更 `broadcastConfig()` 到所有窗口。
- **单实例**：`app.requestSingleInstanceLock()`，重复启动聚焦已有面板，防止叠双音效。

### 音频引擎 `renderer/audio.js`

- 混音拓扑：
  `命中增益(瞬态) → scene母线 → volumeGain(主音量+静音) → 压缩器 → 扬声器`
- **8 套音色** 是声明式「配方」：每个配方是若干 `osc`（振荡器）与 `noise`
  （滤波噪声，用共享白噪声缓冲）part 组成的列表。振荡器带频率滑落（水滴）、
  指数衰减、轻微 detune（钢琴/八音盒泛音），实现相对拟真的短音。
- **场景**：`sceneMultiplier()` 决定整体增益；专注模式叠加**雨声**——循环白噪声
  经高通 → 带通 → 慢 LFO 调制。
- **自定义音效包**：主进程读文件字节 → IPC 传 `ArrayBuffer` → 这里 `decodeAudioData`
  缓存；播放时按 `playbackRate` 变速以支持「越快越高」。

### 悬浮键盘 `renderer/overlay.js`

- 用 HTML/flex 按比例绘制 QWERTY 六行布局，`flex-grow = 键宽权重`。
- 收到 `key` 事件 → `norm()` 归一化键名 → 高亮对应键 + 从键心 `spawnRipple`。
- 波纹维护在 Canvas 上，`requestAnimationFrame` 每帧扩径、衰减、描边+径向渐变填充。
- **空闲淡出**：2.8s 无输入切 `idle` 类，面板降为 `透明度×0.08`。

### 按键映射 `keymaps.js`

- `norm()`：把 DOM 风格（`KeyA`/`Digit1`/`Space`）与 uiohook 风格统一成小写 token。
- `ROWS`：悬浮键盘布局（键位 → code 别名数组）。
- `isPrintable()`：判断是否可打印字符（用于 WPM 统计）。

## 安全

- 所有渲染窗口 `contextIsolation: true` + `nodeIntegration: false`，仅经 `preload.js`
  暴露白名单 IPC。
- 不处理、不上传任何键位内容；声音仅由按键触发，不记录输入值。

## 扩展建议

- **加音色**：在 `audio.js` 的 `PROFILES` 里加一个声明的 `down` / `up` 配方即可，
  同时把新音色登记到 `audio.js` 的 `PROFILE_LABELS` 与设置面板 `renderer.js` 的
  `PROFILES` 数组。
- **加按键布局**：在 `keymaps.js` 的 `ROWS` 与 `overlay.js` 的内嵌布局中同步新增。
