# 使用指南

本文面向普通用户，介绍如何安装、配置与日常使用「键盘音效」。

## 安装与启动

### 前置

- Windows 10 / 11
- 已安装 [Node.js](https://nodejs.org/)（≥ 18，建议 LTS）
- 需要管理员权限的全局键盘钩子**不需要**特别授权即可使用

### 启动

```bash
npm install     # 首次运行执行一次
npm start
```

或直接双击桌面快捷方式「键盘音效」。

启动成功后：

1. 打开「设置面板」窗口
2. 桌面底部出现「透明悬浮键盘」
3. 全局钩子已生效——在任何程序里打字都会发声

> **重要**：关闭设置面板 **不等于** 退出应用。窗口最小化到系统托盘，钩子继续工作。
> 如需完全退出，请使用托盘的右键菜单 → **退出**。

## 界面说明

### ① 音色

8 张卡片对应 8 套音色，点击即**切换并试听**：

| 音色 | 特点 |
|---|---|
| 青轴 | 清脆 click + 段落咔哒 + 回弹，最机械 |
| 红轴 | 线性柔和，轻声 |
| 打字机 | 低频机身筒 + 金属撞击 |
| 木鱼 | 空心木质叩叩 |
| 水滴 | 下行「滴」 |
| 钢琴 | 木质低音 + 泛音 |
| 八音盒 | 明亮延音 |
| 麻将 | 干脆瓷片喀 + 回响 |

### ② 音量

- **整体音量** 滑杆：全局音量百分比
- **静音** 开关：等同 `Ctrl+Alt+K`

### ③ 手感增强

| 选项 | 说明 |
|---|---|
| 按压 + 回弹双音效 | 按下与回弹各发一声，还原轴体段落感 |
| 打字越快音调越高 | 击键越快，音调越高，可调**灵敏度** |
| 音量随机微调 | 每键音量轻微起伏，去机械感，可调**幅度** |

### ④ 特殊键

空格 / 回车 / 退格 各自可：

- **音色**：下拉选择「跟随主音色」或指定 8 套中的任一音色
- **音量**：单独滑杆调节该键音量

### ⑤ 场景模式

| 场景 | 作用 |
|---|---|
| 默认 | 按当前音色 |
| 专注 | 音量压低 + 雨声底噪 |
| 游戏 | 音量加大，更脆 |
| 深夜 | 显著降音，适合夜间 |

底部两个开关：
- **专注 · 雨声底噪**：让专注模式叠加雨声
- **深夜自动降音**：23:00–07:00 自动整体降音

### ⑥ 可视化

| 选项 | 说明 |
|---|---|
| 显示透明悬浮键盘 | 底部悬浮键盘的开关 |
| 悬浮窗透明度 | 键盘面板的透明度 |
| 按键波纹特效 | 按下时从按键中心泛起的波纹 |

### ⑦ 自定义音效包

把包含 `down` / `up` / `space` / `enter` / `backspace` 开头音频文件的文件夹整体导入，即覆盖对应声音。详见 [自定义音效包.md](./自定义音效包.md)。

### ⑧ 今日统计

实时展示今日按键总数、打字速度（WPM）与活跃时长，按天自动结算存档。

## 全局热键

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+K` | 静音 / 取消静音 |
| `Ctrl+Alt+O` | 显示 / 隐藏透明悬浮键盘 |

## 后台运行与系统托盘

- 应用常驻系统托盘（右下角）。
- 右键托盘图标：静音、切换场景、显示/隐藏面板、隐藏悬浮键盘、退出。
- 双击托盘图标：显示 / 隐藏设置面板。
- 关闭设置面板窗口：收缩到托盘，**继续后台运行**。

## 常见问题

**Q：我能听不到声音？**
检查：整体音量、静音开关、系统音量；特殊键若被单独设为「跟随主音色」但没有特殊音效则覆盖主音色。

**Q：换了键位/键盘布局，悬浮键盘对不上？**
目前按标准 QWERTY 布局绘制，非标准布局会高亮到近似位置，功能不受影响。

**Q：会录入密码/隐私吗？**
不会。应用只接收按键事件用于发声与统计，**不上传、不记录键位内容**，数据仅在本地。

**Q：数据存在哪？**
配置与每日统计写在系统用户数据目录：`%APPDATA%\<app>\`（`config.json`、`stats-YYYY-MM-DD.json`）。
