# Changelog

本项目按 [语义化版本](https://semver.org/lang/zh-CN/) 管理。

## [1.0.0] - 2026-09-10

首个正式发布版。

### 新增
- **8 套合成音色**：青轴 / 红轴 / 打字机 / 木鱼 / 水滴 / 钢琴 / 八音盒 / 麻将，全部由 Web Audio API 实时合成，无需任何音频素材。
- **手感增强**：
  - 按压 + 回弹双音效
  - 打字越快音调越高（带灵敏度调节）
  - 音量随机微调，去除机械重复感
- **特殊键**：空格 / 回车 / 退格可单独指定音色与音量。
- **场景模式**：专注（雨声底噪 + 轻音）/ 游戏（响轴更脆）/ 深夜（23:00–07:00 自动降音）。
- **可视化**：透明悬浮键盘实时点亮按键 + Canvas 放射波纹特效，空闲自动淡出。
- **统计**：今日按键数 / 实时 WPM / 活跃时长，按天存档，关闭面板后台持续记录。
- **其他**：
  - `Ctrl+Alt+K` 一键静音、`Ctrl+Alt+O` 开关悬浮窗
  - 自定义音效包导入（down/up/space/enter/backspace）
  - 单实例保护，避免重复启动叠加双音效
  - 托盘常驻，关闭面板不退出
