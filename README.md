# ⌨️ 内置键盘音效 · Keyboard Sound FX

**在你敲击物理键盘时，实时发出机械键盘音效的 Windows 桌面应用**

后台全局运行 · 8 套合成音色 · 透明悬浮波纹键盘 · 听感随打字速度变化

</div>

---

一个基于 **Electron + Web Audio API** 的桌面应用：注册**全局键盘钩子**后，你在任何程序里打字都会发声——青轴的清脆、红轴的柔和、打字机的金属撞击、木鱼的敲击……最妙的是它**不需要任何音频素材**，全部声效由代码实时合成。

**关闭面板窗口不会退出**，它会驻留系统托盘持续工作；透明悬浮键盘会实时点亮你按下的键并泛起波纹。

## ✨ 特性

| 类别 | 内容 |
|---|---|
| 🎛️ 8 套音色 | 青轴 · 红轴 · 打字机 · 木鱼 · 水滴 · 钢琴 · 八音盒 · 麻将 |
| 🖐️ 手感增强 | 按压+回弹双音效 · 打字越快音调越高 · 音量随机微调去除机械感 |
| ⌨️ 特殊键 | 空格 / 回车 / 退格 可单独指定音色与音量 |
| 🌧️ 场景模式 | 专注（雨声底噪+轻音）· 游戏（响轴更脆）· 深夜（自动降音） |
| 🫧 可视化 | 透明悬浮键盘实时显示按键 + 放射波纹特效，空闲自动淡出 |
| 📊 统计 | 今日按键数 · 实时 WPM · 活跃时长（按天存档） |
| ⏯️ 其他 | 一键静音热键 · 自定义音效包导入 · 单实例保护 |

## 🚀 快速开始

```bash
npm install     # 安装依赖
npm start       # 启动应用
```

> 也可直接双击桌面快捷方式「键盘音效」（已建）。
> 详细使用见 [docs/使用指南.md](docs/使用指南.md)。

### 全局热键

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+K` | 静音 / 取消静音 |
| `Ctrl+Alt+O` | 显示 / 隐藏透明悬浮键盘 |

## 🎧 试听音色

设置面板里点击任意音色卡片即可即时试听。8 套音色全部由 Web Audio 逐键合成：
- **青轴**：下压清脆 click + 段落咔哒 + 回弹声
- **红轴**：线性柔和，安静
- **打字机**：低频机身筒 + 金属撞击
- **木鱼**：空心木质「叩叩」+ 桌面回弹
- **水滴**：下行频率的「滴」
- **钢琴**：低频基音 + 多个非谐泛音衰减
- **八音盒**：明亮延音的金属音梳
- **麻将**：干脆的瓷片「喀」+ 二次回响

看合成细节 → [docs/音色设计.md](docs/音色设计.md)

## 📦 自定义音效包

导入一个含如下文件名开头的音频的文件夹，即可替换对应声音：

```
down.mp3       # 普通按键按下
up.mp3         # 普通按键回弹
space.mp3      # 空格
enter.mp3      # 回车
backspace.mp3  # 退格
```

规范见 [docs/自定义音效包.md](docs/自定义音效包.md)。

## 📁 项目结构

```
main.js              主进程：全局钩子 / 统计 / 托盘 / 热键 / 单实例 / IPC
preload.js           渲染进程安全桥接
keymaps.js           按键归一化 / 悬浮键盘布局（主进程）
make-icon.js         生成应用 / 托盘图标
renderer/
  index.*/renderer.js   设置面板
  audio.*/audio.js      隐藏音频引擎（Web Audio 合成 8 套音色 + 场景 rain）
  overlay.*/overlay.js  透明悬浮键盘 + 波纹
docs/                 文档
```

架构详解 → [docs/架构说明.md](docs/架构说明.md)

## 🛠️ 技术栈

- [Electron](https://www.electronjs.org/) — 桌面壳、透明无边框窗口、托盘
- [uiohook-napi](https://www.npmjs.com/package/uiohook-napi) — 全局键盘钩子（N-API，免编译）
- Web Audio API — 音色实时合成、重叠播放、变速变调、雨声底噪
- Canvas 2D — 按键波纹特效
